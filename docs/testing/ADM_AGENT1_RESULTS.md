# Етап №3 — ADM backend + Agent 1: результати

Дата: 08.10.2026. Гілка: `desktop-migration`, основа `d7eab19`. `main` і конфігурація вебзбірки не змінювалися. Перевірка виконана **локально**, ADM не розгорнуто: доступ і характеристики хостингу відсутні.

## Реалізовано

- Окремий PHP backend: MySQL-міграція 001 із десятьма потрібними сутностями, індексами, зовнішніми ключами та унікальністю канонічного ID.
- Справжній Prozorro feed/detail connector, exact/prefix CPV-фільтрація кореня та позицій, збереження спрацьованих фільтрів.
- Обмежений recent-обхід, окремий forward-курсор, повтор захопленої першої сторінки, збереження pending page/index. Оновлення тендера, ревізії, sync event і прогресу в одній транзакції.
- Блокування паралельних колекторів, таймаути, retry/backoff, ліміти запитів/обсягу, санітизований журнал.
- Авторизований JSON API v1: health, scan-status, tenders із курсором подій, конкретний tender. HTTPS для зовнішнього сервера; localhost HTTP лише для тесту.
- Native Rust HTTP → перевірка DTO → SQLite migration 002 → таблиця/картка. Кнопка «Оновити тендери». Секрет читається з приватної AppData-конфігурації, не з React.
- Приклад Cron, інструкція ізольованого розгортання, спільний інтерфейс майбутніх конекторів. Агентів 2–4 не реалізовано.

Файли: `server/src/sources/Prozorro.php`, `server/src/filters/Cpv.php`, `server/src/collector/Collector.php`, `server/api/index.php`, `server/migrations/001_collector.sql`, `src-tauri/src/sync.rs`, `src-tauri/migrations/002_server_sync.sql`, `src/desktop/sync-control.tsx`. Інструкція: [server/README.md](../../server/README.md).

## Середовище

PHP 8.5.9 з cURL, PDO MySQL, OpenSSL; MariaDB 11.4.12 (MySQL-сумісна), окрема `tenderpro_stage3`, порт 3310, bind 127.0.0.1, дані лише `_temp/other/adm-mysql`. Існуючі бази інших проєктів не використовувалися. API — 127.0.0.1:8091. TLS Prozorro перевірявся офіційним CA bundle; перевірка сертифіката не вимикалася.

Тестовий профіль: `4326*`, `34223300-9`, `30*`, `44*`. Широкі `30*` та `44*` потрібні лише для перевірки реального потоку; це не затверджені бізнес-правила. В окремому resilience-профілі — `30*`, `44*`. Excel `subscription_2026-10-06(1).xlsx` не знайдено в проєкті або корені Downloads; коди задано вручну. За вузькими транспортними кодами збігів у перевіреній вибірці не підтверджено.
